# Odin JavaScript Basics

Projects from The Odin Project's Foundations course, built with plain HTML, CSS and JavaScript.

## Projects

| Project | Live demo | Description |
|---|---|---|
| [Rock Paper Scissors](rock-paper-scissors/) | [Play](https://n-shovel.github.io/odin-javascript-basics/rock-paper-scissors/) | A game against the computer; first to 5 points wins. |
| [Etch-a-Sketch](etch-a-sketch/) | [Draw](https://n-shovel.github.io/odin-javascript-basics/etch-a-sketch/) | A resizable drawing grid with black and rainbow modes that darkens on each pass. |
| [Calculator](calculator/) | [Open](https://n-shovel.github.io/odin-javascript-basics/calculator/) | A calculator that chains operations and works with the mouse or keyboard. |

## Running

Each project is live on GitHub Pages (links above). To run one locally, open its `index.html` in a browser.
